# Research notes

Working notes are research artifacts, not automatically manuscript claims.
Assign an evidence class, cite the relevant source record, and state uncertainty
when moving material from this directory into the paper.

The governed handoff path is:

1. [`ADAPTIVE_AUDIO_ARCHITECTURE.md`](ADAPTIVE_AUDIO_ARCHITECTURE.md) for
   architecture transfers and non-transfers;
2. [`COMPARATOR_NOVELTY_MATRIX.md`](COMPARATOR_NOVELTY_MATRIX.md) for prior-art
   overlap and bounded contribution rationale;
3. [`CLAIM_LEDGER.md`](CLAIM_LEDGER.md) for permitted manuscript claims and
   rejected language; and
4. [`paper/manuscript-contract.json`](../../paper/manuscript-contract.json) for
   the frozen thesis, terminology, stages, and section completion gates.
