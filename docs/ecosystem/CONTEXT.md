# Ecosystem context

## Identity

- Repository: `egohygiene/antidote`
- Plane: knowledge and research, with a future product capability
- Holon class: publication today; application capability remains proposed
- Maturity: research and publication foundation with provisional MVP contracts
- Canonical responsibility: personalized adaptive generative-audio research,
  runtime domain contracts, local prototype evidence, and publication source

## Produces

- versioned manuscript source, bibliography, and visual explanations;
- accessible PDF and HTML projections and arXiv-oriented source archives;
- research provenance, source assessments, claim evidence, and future protocols;
- Antidote-owned consent, moment, journey, generation, response, and provenance
  contracts;
- a future local desktop research instrument and privacy-reviewed experiment
  exports.

## Boundaries

- Empathy is migration history, not a runtime dependency.
- Beacon owns reusable publication profiles; Antidote owns its project snapshot,
  research content, scientific ontology, and runtime contracts.
- Reflector is a reference and provenance source for reusable architecture and
  publication patterns, not a source or runtime dependency.
- Ego Hygiene may later provide selected context or host Antidote ports, but
  Antidote remains independently usable and does not inspect sibling internals.
- No workflow submits a manuscript, activates a planned publication, performs a
  clinical action, or silently exports personal data.
- Sensitive participant, journal, therapy, physiological, and identity records
  remain outside this public repository.

## Current integration truth

The research build, checks, publication staging, and repository-intelligence
integration are implemented. The architecture corpus and JSON Schemas are
provisional source. The desktop host, Rust crates, generation worker, model
adapter, formal protocol, study, and Ego Hygiene product integration are not
implemented.
