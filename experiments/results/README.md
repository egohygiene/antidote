# Qualifying result packages

No qualifying result package exists in this directory.

The filenames reserved by
[`../reporting/results-reporting-v1.1.json`](../reporting/results-reporting-v1.1.json)
are future public audit envelopes, not placeholders to populate by hand. Human
source records and free text remain private and are linked only through the
governed opaque, nonce-bound evidence-set commitment. A package may
be created only from a qualifying execution with a named source revision,
protocol and analysis versions, complete denominators, structured record
accounting linked to a private evidence set, failures, exclusions,
missingness, and a claim-ledger disposition. Public packages must not contain
participant-, session-, consent-, or event-level identifiers.

Synthetic fixtures remain under their existing test locations. They must never
be copied here or presented as human-response evidence.
