# Data boundary

No formal study data has been collected.

This directory may later contain public, non-sensitive schemas, synthetic
fixtures, and approved derived data. Do not commit identifiable participant
data, raw private physiological recordings, clinical records, credentials, or
unreviewed personal exports. Data collection requires a versioned protocol,
consent and privacy decisions, and an explicit publication classification.

Cross-language runtime payload definitions belong under `contracts/schemas/`,
not here. This directory is reserved for research-data definitions and approved
evidence. Runtime logs do not become formal study data merely because they are
available.
