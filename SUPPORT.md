## Where to ask

- Open an issue for reproducible bugs, documentation gaps, architecture
  questions, research-source corrections, or workflow problems.
- Use private vulnerability reporting for security, private-context, consent,
  or sensitive-data exposure.
- Do not use repository issues for crisis, medical, therapeutic, or substance-
  use guidance. Antidote is not a clinical service.

## Before opening an issue

Include the revision, operating context, what you were trying to do, commands or
workflow, expected and observed behavior, relevant files/contracts, and
sanitized logs. Use synthetic inputs and remove credentials, paths containing
private identity, journal or therapy text, participant data, and personal audio.
