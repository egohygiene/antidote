\section{Working protocol checklist}
\label{app:working-protocol-checklist}

Before formal data collection, the project must freeze or explicitly version:

\begin{enumerate}
  \item the current-state and desired-trajectory representations;
  \item the semantic control vocabulary and mutation rules;
  \item the audio generator, parameters, and output checksums;
  \item acoustic feature extraction methods;
  \item subjective, behavioral, and optional physiological measures;
  \item the analysis plan, missing-data handling, and stopping rules;
  \item safety, privacy, consent, and ethics-review decisions; and
  \item the rules for separating observations, interpretations, and claims.
\end{enumerate}
