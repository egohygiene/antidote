# Governed manuscript tables

Active scientific table sources live here as LaTeX fragments. When a table is
data-driven, retain the canonical CSV, TSV, or JSON input and deterministic
rendering script beside the fragment. Table identity, placement, caption,
accessibility text, state, provenance, and claims remain governed by
[`paper/visuals/manifest.json`](../visuals/manifest.json).

Most planned table filenames remain visibly provisional until their owning
evidence and manuscript issues authorize content. The three Results tables are
a deliberate exception: `scripts/generate_results_reporting.py` projects a
governed empty state from
`experiments/reporting/results-reporting-v1.1.json`. Those drafts identify future
source records, protocol versions, analyses, and blocked states while containing
no result values. A value-bearing revision must be generated from a qualifying
result package and reviewed through the claim ledger; values are never entered
directly in LaTeX.

`risk-mitigation-status.tex` is generated by
`scripts/generate_risk_table.py` from the issue #43
`risk-mitigation-status.json` audit. It distinguishes synthetic-only behavior,
specified but unverified controls, unresolved risks, and blocked activities.
The table authorizes no collection and cannot be edited independently of its
machine-readable source.
