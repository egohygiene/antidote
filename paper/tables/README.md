# Governed manuscript tables

Active scientific table sources live here as LaTeX fragments. When a table is
data-driven, retain the canonical CSV, TSV, or JSON input and deterministic
rendering script beside the fragment. Table identity, placement, caption,
accessibility text, state, provenance, and claims remain governed by
[`paper/visuals/manifest.json`](../visuals/manifest.json).

`evidence-claim-classification.tex`, `measurement-evidence-matrix.tex`, and
`protocol-evidence-audit.tex` are final, deterministic projections generated by
`scripts/generate_visual_tables.py`. Their inputs are the canonical evidence
taxonomy, corrected frozen protocol, lock, governed reporting contract, and
claim boundaries. They describe classifications and current availability; they
do not contain participant observations.

The three Results tables are final empty-state projections generated by
`scripts/generate_results_reporting.py` from
`experiments/reporting/results-reporting-v1.1.json`. Final describes their
publication quality and accurate unavailable-state reporting, not completion of
T0, T1, or H1. A value-bearing revision must be generated from a qualifying
result package and reviewed through the claim ledger; values are never entered
directly in LaTeX.

`research-landscape-comparator.tex` is generated from the governed comparator
matrix by `scripts/generate_comparator_table.py`.

`risk-mitigation-status.tex` is generated by
`scripts/generate_risk_table.py` from the issue #43
`risk-mitigation-status.json` audit. It distinguishes synthetic-only behavior,
specified but unverified controls, unresolved risks, and blocked activities.
The table authorizes no collection and cannot be edited independently of its
machine-readable source.
