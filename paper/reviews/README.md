# Manuscript reviews

This directory retains publication-stage review evidence and tracked
dispositions. A review record describes the source state it examined, its
actual reviewer-independence boundary, primary-source spot checks, resolved and
accepted findings, justified deferrals, and required post-merge verification.

Repository review is not scientific peer review. Do not use a passed record to
claim venue acceptance, ethics approval, clinical validation, safety, efficacy,
or endorsement.

For version 0.1.0, read the
[review narrative](reviewable-preprint-v0.1.0.md) together with its
[machine-readable record](reviewable-preprint-v0.1.0.json).
