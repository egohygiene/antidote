# Generated visual prompt records

No active Antidote scientific visual currently uses image generation.

If a future manifest entry selects `generated-editorial`, add one JSON record
here named after the visual slug. Record the visual ID, model/provider and exact
version, complete prompt and negative prompt, seed or equivalent settings when
available, generation date, source image identities, output SHA-256, applicable
terms/license, AI disclosure text, and the human reviewer who verified every
visible label and scientific implication.

Prompt records are provenance. They do not make generated artwork suitable for
exact architecture, data visualization, or evidence-bearing labels.
