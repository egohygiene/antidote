# ANT-TBL-004 - Control-adherence results

## Scientific purpose

Reserve a reproducible technical-results structure without creating evidence before qualifying runs exist.

## Required content

Eventually include run identity, requested controls, measured realization, adherence estimate, uncertainty, verification, and failure notes.

## Evidence and claim boundary

Governed by ANT-OBS-002, ANT-CLM-003, and ANT-NEG-004. Synthetic fixtures may validate code but cannot become human outcomes.

## Source plan

Generate LaTeX from provenance-linked technical outputs only after issue #41 authorizes their evidence class.

## Accessibility plan

Use explicit units, textual verification states, machine-readable source data, and explanatory notes for missing metrics.

## Failure conditions

Reject hand-entered result values, absent hashes, unqualified simulated runs, or any implication of felt response or benefit.
