# ANT-FIG-010 — MVP session evidence interface

## Scientific purpose

Reserve a reviewable interface composite that can demonstrate implemented
authority and provenance boundaries without presenting a UI as evidence of
human benefit.

## Required content

- Consent scope and bounded context status.
- Editable journey and explicit approval state.
- Generation progress, cancellation, and failure state.
- Deliberate playback and immediately available stop control.
- Separated response and adverse-response capture.
- Source revision and explicit synthetic-or-approved-data label.

## Evidence and claim boundary

The final visual is contingent on qualifying implementation evidence. It may
show that controls exist at a named revision; it cannot establish usability,
safety, personalization quality, clinical efficacy, or actual private use.

## Source plan

Capture only a reproducible reviewed build from issue #18 or its successor.
Use synthetic fixtures unless separate approval exists. Retain capture steps,
revision, operating-system context, redaction review, and image checksum.

## Accessibility plan

Prefer a small annotated composite over an unreadable full-window screenshot.
Provide sufficient crop scale, contrast, numbered callouts, alt text, and a
long description following the actual interaction order.

## Failure conditions

- Private, personal, participant, token, or path data is visible.
- The source revision or fixture classification is missing.
- Controls shown do not exist in the referenced build.
- The caption implies user benefit or completed empirical evaluation.
